---
title: "Resume / start campaign"
sidebarTitle: "Resume campaign"
description: "Start a draft or scheduled campaign, or resume a paused one. The server picks the right action based on the campaign's current status."
api: "POST /campaigns/{id}/resume"
---

This is the same single button the dashboard uses. The server looks at the campaign's current status and:

- `draft` or `scheduled` → starts the campaign.
- `paused` → resumes the campaign from where it left off.

## Path parameters

<ParamField path="id" type="string" required>
  UUID of the campaign.
</ParamField>

## Request

<CodeGroup>

```bash cURL
curl -X POST "https://api.verbeo.ai/v1/campaigns/0175091d-2c3b-4aef-8c45-dbbe24f7b3ff/resume" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```javascript Node.js
await fetch(`https://api.verbeo.ai/v1/campaigns/${campaignId}/resume`, {
  method: "POST",
  headers: { Authorization: `Bearer ${process.env.VERBEO_API_KEY}` },
});
```

```python Python
requests.post(
    f"https://api.verbeo.ai/v1/campaigns/{campaign_id}/resume",
    headers={"Authorization": f"Bearer {os.environ['VERBEO_API_KEY']}"},
)
```

</CodeGroup>

## Response

`200 OK`.

```json
{
  "success": true,
  "data": {
    "campaign_id": "0175091d-2c3b-4aef-8c45-dbbe24f7b3ff",
    "status": "running"
  }
}
```

## Errors

| Code                  | Status | When it happens                                                                                  |
|-----------------------|--------|--------------------------------------------------------------------------------------------------|
| `CAMPAIGN_NOT_FOUND`  | 404    | The campaign doesn't exist in your workspace.                                                    |
| `INVALID_STATUS`      | 409    | The campaign is `running`, `warmup`, `dormant`, `completed`, or `cancelled` — only `draft`, `scheduled`, or `paused` campaigns can be resumed. |
| `ORCHESTRATOR_ERROR`  | 502    | Upstream campaign-orchestrator returned an unexpected error.                                     |

See [Campaigns overview](/api-reference/campaigns/overview#error-codes) and [Errors](/api-reference/errors) for the standard envelope.
