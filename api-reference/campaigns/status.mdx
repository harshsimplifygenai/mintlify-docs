Use this endpoint to check where a campaign is in its lifecycle and how many calls have completed. The response is small and read-only — safe to poll on a short interval (every few seconds) for a live progress UI. If you need a per-contact breakdown, use [`/campaign/stats`](/api-reference/campaigns/stats) instead.

## Endpoint

```
POST https://api.verbeo.ai/v1/campaign/status
```

## Request body

<ParamField body="campaign_id" type="string" required>
  UUID of the campaign.
</ParamField>

## Request

<CodeGroup>

```bash cURL
curl -X POST "https://api.verbeo.ai/v1/campaign/status" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "campaign_id": "0175091d-2c3b-4aef-8c45-dbbe24f7b3ff" }'
```

```javascript Node.js
const res = await fetch("https://api.verbeo.ai/v1/campaign/status", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.VERBEO_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ campaign_id: "0175091d-2c3b-4aef-8c45-dbbe24f7b3ff" }),
});
const { data } = await res.json();
```

```python Python
import os, requests

res = requests.post(
    "https://api.verbeo.ai/v1/campaign/status",
    headers={"Authorization": f"Bearer {os.environ['VERBEO_API_KEY']}"},
    json={"campaign_id": "0175091d-2c3b-4aef-8c45-dbbe24f7b3ff"},
)
data = res.json()["data"]
```

</CodeGroup>

## Status meanings

| Status | Description |
|---|---|
| `draft` | Created but never started. Editable. |
| `scheduled` | Waiting for `scheduled_at`. Editable. |
| `warmup` | Spinning up the call pool before dispatch. |
| `in-progress` | Actively dialing contacts. |
| `paused` | Dispatch suspended. Editable. |
| `dormant` | Inside the lifecycle but blocked (typically outside `business_hours`, or the retry pool is empty). Resumes automatically. |
| `completed` | Every contact reached a terminal state. |
| `cancelled` | Archived. Terminal. |

## Error responses

| Code | Status | Cause |
|---|---|---|
| `MISSING_FIELD` | 400 | `campaign_id` not provided. |
| `UNAUTHORIZED` | 401 | Missing/invalid API key. |
| `CAMPAIGN_NOT_FOUND` | 404 | Campaign UUID isn't in your workspace. |
