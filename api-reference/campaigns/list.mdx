## Query parameters

<ParamField query="limit" type="number" default="20">
  Page size, between `1` and `100`.
</ParamField>

<ParamField query="offset" type="number" default="0">
  Number of records to skip. Use the value of `pagination.next_cursor` from the previous response.
</ParamField>

<ParamField query="status" type="string">
  Restrict the response to campaigns in a single status: `draft`, `scheduled`, `running`, `dormant`, `paused`, `completed`, or `cancelled`.
</ParamField>

## Request

<CodeGroup>

```bash cURL
curl "https://api.verbeo.ai/v1/campaigns?limit=20&status=running" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```javascript Node.js
const res = await fetch(
  "https://api.verbeo.ai/v1/campaigns?limit=20&status=running",
  { headers: { Authorization: `Bearer ${process.env.VERBEO_API_KEY}` } },
);
const { data, pagination } = await res.json();
```

```python Python
import os, requests

res = requests.get(
    "https://api.verbeo.ai/v1/campaigns",
    params={"limit": 20, "status": "running"},
    headers={"Authorization": f"Bearer {os.environ['VERBEO_API_KEY']}"},
)
body = res.json()
campaigns = body["data"]
```

</CodeGroup>
