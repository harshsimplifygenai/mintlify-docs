---
title: "Pause campaign"
sidebarTitle: "Pause campaign"
description: "Pause a running or dormant campaign. Stops new dials; in-flight calls finish naturally."
api: "POST /campaigns/{id}/pause"
---

## Path parameters

<ParamField path="id" type="string" required>
  UUID of the campaign.
</ParamField>

## Request

<CodeGroup>

```bash cURL
curl -X POST "https://api.verbeo.ai/v1/campaigns/0175091d-2c3b-4aef-8c45-dbbe24f7b3ff/pause" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```javascript Node.js
await fetch(`https://api.verbeo.ai/v1/campaigns/${campaignId}/pause`, {
  method: "POST",
  headers: { Authorization: `Bearer ${process.env.VERBEO_API_KEY}` },
});
```

```python Python
requests.post(
    f"https://api.verbeo.ai/v1/campaigns/{campaign_id}/pause",
    headers={"Authorization": f"Bearer {os.environ['VERBEO_API_KEY']}"},
)
```

</CodeGroup>

## Response

`200 OK`.

```json
{
  "success": true,
  "data": {
    "campaign_id": "0175091d-2c3b-4aef-8c45-dbbe24f7b3ff",
    "status": "paused"
  }
}
```

To resume later, call [Resume](/api-reference/campaigns/resume).

## Errors

| Code                  | Status | When it happens                                                                                |
|-----------------------|--------|------------------------------------------------------------------------------------------------|
| `CAMPAIGN_NOT_FOUND`  | 404    | The campaign doesn't exist in your workspace.                                                  |
| `INVALID_STATUS`      | 409    | The campaign is `draft`, `scheduled`, `paused`, `completed`, or `cancelled` — only `running`, `warmup`, or `dormant` campaigns can be paused. |
| `ORCHESTRATOR_ERROR`  | 502    | Upstream campaign-orchestrator returned an unexpected error.                                   |

See [Campaigns overview](/api-reference/campaigns/overview#error-codes) and [Errors](/api-reference/errors).
