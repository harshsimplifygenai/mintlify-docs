The Verbeo REST API gives you programmatic control over batch campaigns. All resources are accessible over HTTPS and exchange data as JSON.

## Base URL

Every API request is sent to the following base URL:

```
https://api.verbeo.ai/v1
```

## Request format

The API follows REST conventions. Resources are addressed by URL, and the HTTP method describes the operation: `GET` to read, `POST` to create or trigger an action, `PATCH` to update, `DELETE` to remove. Send request bodies as JSON with the `Content-Type: application/json` header.

```bash
curl -X POST "https://api.verbeo.ai/v1/campaigns" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"campaign_name": "Spring Outreach", "agent_id": "...", "phone_number": "+15551234567", "contacts": [...]}'
```

## Conventions

Every Verbeo response uses one of two envelopes:

- **Success** — `{ "success": true, "data": ... }`. List endpoints add `pagination`. See [Responses](/api-reference/responses).
- **Error** — `{ "success": false, "error": { "code": "...", "message": "...", "details": [...] } }`. Branch on `error.code`, never on the human-readable message. See [Errors](/api-reference/errors) for the full code reference.

## Authentication

All requests require a Bearer token in the `Authorization` header. See [API authentication and keys](/api-reference/authentication) for full details.

## Versioning

The Verbeo API is currently at version 1.0. The API follows an additive compatibility policy: new fields may appear in responses without a breaking-change notice. Fields and endpoints will not be removed or renamed without advance notice.

## Rate limits

Rate limits are applied per workspace. The specific thresholds depend on your plan. Contact [support@verbeo.ai](mailto:support@verbeo.ai) to learn about your workspace limits or to request an increase.
