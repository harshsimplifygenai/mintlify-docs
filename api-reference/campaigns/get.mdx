## Path parameters

<ParamField path="id" type="string" required>
  UUID of the campaign.
</ParamField>

## Request

<CodeGroup>

```bash cURL
curl "https://api.verbeo.ai/v1/campaigns/0175091d-2c3b-4aef-8c45-dbbe24f7b3ff" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```javascript Node.js
const res = await fetch(
  `https://api.verbeo.ai/v1/campaigns/${campaignId}`,
  { headers: { Authorization: `Bearer ${process.env.VERBEO_API_KEY}` } },
);
const { data } = await res.json();
```

```python Python
res = requests.get(
    f"https://api.verbeo.ai/v1/campaigns/{campaign_id}",
    headers={"Authorization": f"Bearer {os.environ['VERBEO_API_KEY']}"},
)
campaign = res.json()["data"]
```

</CodeGroup>

## Errors

`CAMPAIGN_NOT_FOUND` (404) when the campaign doesn't exist in your workspace. See [Campaigns overview](/api-reference/campaigns/overview#error-codes) and [Errors](/api-reference/errors).
